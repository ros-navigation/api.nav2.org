# PolygonObject Message

**Package:** `nav2_msgs`  
**Category:** Vector Map Messages

Polygon object for vector map representation on costmaps

## Message Definition

| Field | Type | Description |
|-------|------|-------------|
| `header` | `std_msgs/Header` | Standard ROS header with timestamp and frame |
| `uuid` | `unique_identifier_msgs/UUID` | Unique identifier for this polygon object |
| `points` | `geometry_msgs/Point32[]` | Vertices defining the polygon boundary |
| `closed` | `bool` | Whether the polygon is closed (last vertex connects to first) |
| `value` | `int8` | Cost value to apply within the polygon |



## Usage Examples

### Python

```python
import rclpy
from rclpy.node import Node
from uuid import uuid4
from unique_identifier_msgs.msg import UUID
from nav2_msgs.msg import PolygonObject
from geometry_msgs.msg import Point32

class PolygonObjectPublisher(Node):
    def __init__(self):
        super().__init__('polygonobject_publisher')
        self.publisher = self.create_publisher(PolygonObject, 'polygonobject', 10)
        
    def publish_message(self):
        msg = PolygonObject()
        msg.header.stamp = self.get_clock().now().to_msg()
        msg.header.frame_id = 'map'
        msg.uuid = UUID(uuid=list(uuid4().bytes))
        p1 = Point32(x=0.0, y=0.0, z=0.0)
        p2 = Point32(x=2.0, y=0.0, z=0.0)
        p3 = Point32(x=2.0, y=2.0, z=0.0)
        p4 = Point32(x=0.0, y=2.0, z=0.0)
        msg.points = [p1, p2, p3, p4]
        msg.closed = True
        msg.value = 100
        self.publisher.publish(msg)
```

### C++

```cpp
#include "rclcpp/rclcpp.hpp"
#include "nav2_msgs/msg/polygon_object.hpp"
#include "geometry_msgs/msg/point32.hpp"

class PolygonObjectPublisher : public rclcpp::Node
{
public:
    PolygonObjectPublisher() : Node("polygonobject_publisher")
    {
        publisher_ = create_publisher<nav2_msgs::msg::PolygonObject>("polygonobject", 10);
    }

    void publish_message()
    {
        auto msg = nav2_msgs::msg::PolygonObject();
        msg.header.stamp = now();
        msg.header.frame_id = "map";
        // UUID is typically set by the server or generated by the client
        geometry_msgs::msg::Point32 p1, p2, p3, p4;
        p1.x = 0.0; p1.y = 0.0; p1.z = 0.0;
        p2.x = 2.0; p2.y = 0.0; p2.z = 0.0;
        p3.x = 2.0; p3.y = 2.0; p3.z = 0.0;
        p4.x = 0.0; p4.y = 2.0; p4.z = 0.0;
        msg.points = {p1, p2, p3, p4};
        msg.closed = true;
        msg.value = 100;
        publisher_->publish(msg);
    }

private:
    rclcpp::Publisher<nav2_msgs::msg::PolygonObject>::SharedPtr publisher_;
};
```
