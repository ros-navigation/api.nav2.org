# CircleObject Message

**Package:** `nav2_msgs`  
**Category:** Vector Map Messages

Circle object for vector map representation on costmaps

## Message Definition

| Field | Type | Description |
|-------|------|-------------|
| `header` | `std_msgs/Header` | Standard ROS header with timestamp and frame |
| `uuid` | `unique_identifier_msgs/UUID` | Unique identifier for this circle object |
| `center` | `geometry_msgs/Point32` | Center point of the circle |
| `radius` | `float32` | Radius of the circle in meters |
| `fill` | `bool` | Whether the circle is filled or only an outline |
| `value` | `int8` | Cost value to apply within the circle |



## Usage Examples

### Python

```python
import rclpy
from rclpy.node import Node
from uuid import uuid4
from unique_identifier_msgs.msg import UUID
from nav2_msgs.msg import CircleObject

class CircleObjectPublisher(Node):
    def __init__(self):
        super().__init__('circleobject_publisher')
        self.publisher = self.create_publisher(CircleObject, 'circleobject', 10)
        
    def publish_message(self):
        msg = CircleObject()
        msg.header.stamp = self.get_clock().now().to_msg()
        msg.header.frame_id = 'map'
        msg.uuid = UUID(uuid=list(uuid4().bytes))
        msg.center.x = 5.0
        msg.center.y = 3.0
        msg.center.z = 0.0
        msg.radius = 1.5
        msg.fill = True
        msg.value = 100
        self.publisher.publish(msg)
```

### C++

```cpp
#include "rclcpp/rclcpp.hpp"
#include "nav2_msgs/msg/circle_object.hpp"

class CircleObjectPublisher : public rclcpp::Node
{
public:
    CircleObjectPublisher() : Node("circleobject_publisher")
    {
        publisher_ = create_publisher<nav2_msgs::msg::CircleObject>("circleobject", 10);
    }

    void publish_message()
    {
        auto msg = nav2_msgs::msg::CircleObject();
        msg.header.stamp = now();
        msg.header.frame_id = "map";
        // UUID is typically set by the server or generated by the client
        msg.center.x = 5.0;
        msg.center.y = 3.0;
        msg.center.z = 0.0;
        msg.radius = 1.5;
        msg.fill = true;
        msg.value = 100;
        publisher_->publish(msg);
    }

private:
    rclcpp::Publisher<nav2_msgs::msg::CircleObject>::SharedPtr publisher_;
};
```
