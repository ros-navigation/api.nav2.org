# Planning Actions - Lyrical

This page lists all planning actions available in Nav2 for the lyrical distribution.

## Available Actions (5)


### [ComputeRoute](/actions/lyrical/computeroute.html)

**Package:** `nav2_msgs`

Compute a high-level route between waypoints using graph search

---

### [SmoothPath](/actions/lyrical/smoothpath.html)

**Package:** `nav2_msgs`

Generate a smoother, kinematically feasible path from a discrete path

---

### [ComputePathThroughPoses](/actions/lyrical/computepaththroughposes.html)

**Package:** `nav2_msgs`

Compute an optimal path connecting multiple poses in sequence

---

### [ComputeAndTrackRoute](/actions/lyrical/computeandtrackroute.html)

**Package:** `nav2_msgs`

Compute and actively track a route with dynamic replanning

---

### [ComputePathToPose](/actions/lyrical/computepathtopose.html)

**Package:** `nav2_msgs`

Compute an optimal path from current position to a target pose
